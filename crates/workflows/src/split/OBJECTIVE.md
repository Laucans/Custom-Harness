# Objective

Turn one approved, deliverable piece of work into the concrete,
individually-assignable tasks that actually deliver it.

**Trigger.** A piece of work has been reviewed and explicitly approved to
proceed.

**What it does.** Breaks it into discrete tasks, each scoped narrowly
enough to be picked up and finished on its own. Each task is flagged for
whether it needs a person's direct involvement or can be carried out
independently, and the tasks are ordered so each one can build on the last.

**Why it matters.** A plan that is never broken into bounded, assignable
pieces does not get executed — someone has to decide where the lines are.
This makes that decision explicit, visible, and consistent rather than left
to whoever happens to pick the work up.

**What "done" looks like.** The approved piece of work has a complete set
of ordered tasks under it, each one scoped and flagged clearly enough to
start on immediately.

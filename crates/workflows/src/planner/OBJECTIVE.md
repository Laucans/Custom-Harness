# Objective

Turn one big, still-vague goal into an ordered set of smaller goals that can
actually be delivered one at a time.

**Trigger.** A large goal has been explicitly marked ready by a person, and
has no delivery plan under it yet.

**What it does.** Reads what has actually been built so far — not what was
assumed or hoped — then proposes a sequence of smaller, deliverable pieces,
each a coherent step toward the large goal, ordered so each step can build
on what came before.

**Why it matters.** Large goals fail when nobody turns them into a concrete,
checkable sequence. This produces that sequence from the real, current state
of things rather than from stale assumptions, and leaves every piece clearly
described before any work on it starts.

**What it deliberately does not do.** It does not start the work itself,
and it does not decide the large goal is finished — it only lays out the
path toward it.

**What "done" looks like.** The large goal has a complete, ordered set of
smaller goals under it, each one described well enough to be picked up next.

# Objective

Turn a thin, early description of a piece of work into one detailed enough
that someone could actually start building it without having to guess.

**Trigger.** A piece of work exists but is described only loosely — a
title and an intention, not a real specification.

**What it does.** Builds out the missing detail in passes, each pass
adding what the previous one left out, until the description covers what is
being built, why, what is explicitly excluded, and how to confirm the result
actually works once built.

**Why it matters.** Vague descriptions of work cause rework and scope
drift once building starts. Closing that gap before any work begins is
cheaper than discovering the gap mid-build.

**What it deliberately does not do.** It does not pad a description that
is already complete — finding nothing left to add is a legitimate, reported
outcome, not a failure to try harder.

**What "done" looks like.** The piece of work has a description complete
enough to hand to someone else and have them start immediately.
